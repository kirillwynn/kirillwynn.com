# kirillwynn.com

kirillwynn.com is a greenfield personal publishing site controlled by its owner. It will combine public writing, member discussion, subscriptions, and a small bridge to the owner's external profiles; it is not a social-media aggregator.

## Current status

The repository currently contains only its documentation and governance foundation. There is no runnable application, dependency setup, deployment, or runtime architecture yet.

## Product scope

The planned non-finance v1 includes an accessible public feed and posts, first-party authoring and administration, verified member identity, comments and custom reactions, subscription email, search, media, and safe publication workflows. Architecture and implementation choices remain subject to focused ADRs and separately authorized milestones.
